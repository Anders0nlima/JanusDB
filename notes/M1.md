# M1 — Página e arquivo de dados

O M1 implementa a leitura e escrita de páginas de tamanho fixo
sobre um arquivo comum, utilizando as operações seek, read e write
em modo binário.

Também foi implementada a gravação e leitura de um registro de 8 bytes
no slot 0 da página 2. A página 2 começa no byte 8192 do arquivo,
pois cada página possui 4096 bytes. Como o cabeçalho ocupa 16 bytes,
o registro do slot 0 começa no byte 8208.


## Principais Dificuldades

A principal dificuldade neste módulo (M1) foi entender como tudo isso é aplicado na prática: como visualizar o dado saindo de uma variável no Python, sendo transformado em bytes brutos e persistido fisicamente no disco. Além disso, foi um desafio pensar defensivamente e projetar validações rigorosas (como verificar se a página lida ou escrita tem exatamente `PAGE_SIZE` bytes), garantindo que o banco de dados falhe alto (fail fast) em vez de engolir erros silenciosos que corromperiam a base em etapas futuras.
